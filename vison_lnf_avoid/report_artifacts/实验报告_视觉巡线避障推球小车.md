## 摘要

本课题面向电子技术课程设计中的循迹、避障和自主创新任务，设计并实现了一套基于 ESP32-S3 的三轮全向视觉小车。系统采用单个 USB UVC 摄像头完成黑线采样、终点识别、红蓝球识别和洞口定位，以 HC-SR04 完成前向测距，以三路霍尔编码器形成低速运动反馈，并通过 TB6612 类三路电机驱动控制全向底盘。软件按照感知、决策、运动和执行四层组织，在 10 ms 控制周期内先完成视觉巡线与一次性横移避障，确认终点横条后切换到推球任务，将红球推入左洞、蓝球推入右洞。

针对软件 JPEG 解码延迟、低速电机堵转、视觉中心死区、弯道误判、丢线搜索和近球旋转导致目标滚失等问题，工程采用双尺度解码、专核视觉任务、四块伪红外采样、PD 巡线、编码器分段扫线、轮级 PI 速度环以及 14 状态推球控制器。当前源码中的 6 组宿主机单元测试均已重新编译运行并通过，覆盖运动学混合、伪红外、巡线、避障、球视觉和推球时序。

**关键词**：ESP32-S3；UVC 摄像头；三轮全向车；视觉巡线；超声波避障；状态机；PI 控制；推球入洞

## 1 课题内容及技术方案

### 1.1 课题目标

本课题使用 ESP32-S3-DevKitC-1 作为核心控制器，完成三轮全向小车的巡线、避障和视觉自主任务。基础任务要求小车沿黑线稳定运行，遇到障碍物后完成横移绕行并重新寻找路线；创新任务要求小车在终点后切换到视觉伺服，将两种颜色的球推入指定洞口。最终系统不依赖物理四路红外板，而是让摄像头兼任巡线与目标识别传感器。

### 1.2 总体技术路线

```
图 1 系统信息流与控制链

USB UVC 摄像头 ──MJPEG──> 软件解码 ──> 伪红外四通道 ──> PD 巡线
                          │                    └─> 终点确认
                          └─> 红球/蓝球/洞口检测 ──> 14 状态推球控制器

HC-SR04 ──────────────> 距离状态 ──> 一次性避障状态机 ─┐
三路编码器 ───────────> 轮速与里程反馈 ────────────────┼─> 全向运动混合 ─> 三路 PWM ─> 电机
巡线/推球控制器 ─────> forward/lateral/turn ───────────┘

旁路诊断：ST7735 LCD + Wi-Fi SoftAP + HTTP MJPEG 与 JSON 状态
```

### 1.3 方案选择

| 设计环节 | 采用方案 | 选择依据 |
|----------|----------|----------|
| 主控制器 | ESP32-S3 + ESP-IDF | 双核、USB OTG、Wi-Fi、PCNT、LEDC 等外设完整，适合多任务视觉控制 |
| 巡线传感 | UVC 摄像头四块伪红外 | 复用同一视觉传感器，采样结果与原四路掩码接口兼容 |
| 避障测距 | HC-SR04 | 结构简单，60 ms 周期即可满足前向近距离触发 |
| 运动底盘 | 三轮全向运动学 | 允许前进、横移、原地转向，能直接实现绕障和对球横向对准 |
| 控制方法 | 开环 PD + 条件启用轮级 PI | 巡线响应快；横移和低速阶段用反馈克服静摩擦与轮间差异 |

| 任务组织 | 分层状态机 | 每个 tick 只依据输入更新状态和输出，便于调试及宿主机单元测试 |

## 3 数字系统总体设计

### 3.1 运行阶段与时序

系统上电完成驱动、编码器、超声波、云台、LCD、Wi-Fi 与摄像头初始化后，进入 10 ms 周期控制循环。RUN_PHASE_LINE 阶段先计算避障输出；避障未激活时再运行巡线控制器。只有伪红外连续 3 帧确认终点全黑，系统才停车、切换摄像头到 PUSH 解码尺度并进入 RUN_PHASE_BALL。若巡线停止但没有终点确认，则锁定停车，防止普通丢线误触发推球。

| 时基 | 周期或阈值 | 作用 |
|------|------------|------|
| 主控制循环 | 10 ms | 状态机统一 tick；更新运动命令 |
| 超声波采样 | 60 ms | 前向距离刷新 |
| 速度反馈 | 50 ms | 三轮编码器测速与 PI 更新 |
| LCD 刷新 | 200 ms | 降低显示开销 |
| 摄像头请求 | 480×320 MJPEG 25 fps | 原始输入；解码任务按处理能力丢帧 |
| 视觉新鲜度 | 推球 500 ms；摄像头 1500 ms | 过期结果不参与控制并可触发锁定 |

### 3.2 并发与资源分配

UVC 回调只完成 JPEG 数据复制并释放信号量，不在回调中执行解码。视觉任务固定在 core 1，控制循环和 Wi-Fi 主要运行在 core 0。解码期间到达的新帧直接丢弃，避免待处理队列不断增长造成控制使用过时画面。最新 RGB 分析结果和最新 JPEG 流快照分别通过同步对象保护。

### 3.3 安全策略

- 摄像头断开或画面超时后锁定停车，避免盲行。
- 避障阶段设置测距过期、运动超时、编码器堵转和最大横移量保护。
- 丢线搜索设置两段扫描、5 s 总超时和 400 ms 无进展保护。
- 推球任务设置 180 s 总超时，关键定距状态复用编码器堵转看门狗。
- 终点和故障状态均为粘滞状态，需要复位才能再次启动。

## 4 数字系统详细设计及代码实现

### 4.1 视觉采集与双尺度解码

摄像头输入为 480×320 MJPEG。巡线阶段使用 1/8 解码得到约 60×40 工作图，降低计算量；推球阶段使用 1/4 解码得到约 120×80 工作图，提高远处小球和洞口的可分辨性。摄像头倒装由水平和垂直翻转统一修正，伪红外、球视觉和网页叠加层使用相同逻辑坐标。

### 4.2 伪红外巡线感知

在逻辑图像高度 70% 的位置设置四个采样块，其横向中心依次为图像宽度的 65%、54%、47% 和 35%。每块根据采样行平均亮度自适应计算黑色阈值，阈值为行均值减 40，并限制在 12 至 220。块内暗像素不少于 2 个即置位，对应 bit0 至 bit3。内侧两个块跨越画面中心，使居中黑线可形成 0x06，从结构上消除中心缝隙造成的假丢线。

```c
/* 代码 1 伪红外掩码与终点确认逻辑摘要 */
threshold = clamp(mean_luma_of_sample_row - 40, 12, 220);
for each channel block i:
    dark = count(pixel_luma <= threshold);
    if (dark >= 2) mask |= (1U << i);
finish_candidate = (mask == 0x0F);
finish_detected = finish_candidate for 3 consecutive frames;
```

### 4.3 PD 巡线与急弯处理

巡线误差只使用内侧 CH2 和 CH3：仅 CH2 黑时 e=+1，仅 CH3 黑时 e=-1，两者相同则 e=0。外侧 CH1 和 CH4 不直接放大普通跟踪误差，而仅用于急弯武装，避免宽线或缓弯导致过早大幅转向。转向量采用离散 PD，前进速度随误差绝对值降低。

```c
/* 代码 2 巡线 PD 核心公式 */
derivative = last_cycle_tracking ? error - last_error : 0;
turn    = clamp(70 * error + 15 * derivative, -250, 250);
forward = clamp(170 - 20 * abs(error), 120, 170);
```

急弯必须满足：车辆已稳定居中并重新武装；同侧外通道持续 30 ms；随后 450 ms 窗口内出现全白。确认后以 turn=±200 定向旋转，至少 60 ms；中心通道连续恢复 30 ms 后进入 50 ms 低速退出。600 ms 内未恢复则转入丢线搜索。

### 4.4 编码器分段丢线搜索

出现全白且历史上已经看到黑线时，控制器固定先向右搜索 120°，再向左搜索 240°，覆盖原朝向两侧的 240° 扇区。角度以左右轮绝对增量之和近似，不依赖编码器正负接线；接近目标时降低转速，每段结束停车 30 ms。转动和停留期间均持续检测黑线，一旦重获有效掩码立即回到跟踪。

| 搜索段 | 方向 | 目标计数 | 速度 |
|--------|------|----------|------|
| 第 1 段 | 右转 | 4×160=640 | 230，末段 180 |
| 第 2 段 | 左转 | 8×160=1280 | 230，末段 180 |

### 4.5 一次性超声波避障

```
图 2 避障状态机
ARMED → BRAKE → STRAFE_LEFT → FORWARD_PASS → STRAFE_RIGHT_FIND_LINE → COMPLETE
                                          └──────────────→ FAULT_STOP
```

距离进入 150 mm 后将巡线前进速度限制为 90；连续 2 次不大于 50 mm 时触发避障。制动 100 ms 后以横移命令 120 左移，直到距离连续 3 次大于 120 mm，再额外横移 250 ms 留出安全余量；随后左右轮闭环前进累计 1000 计数；最后右移并等待视觉重新稳定对中。避障只允许执行一次，完成后重置巡线控制器。

### 4.6 三轮全向运动学与轮级 PI

上层统一输出 forward、lateral 和 turn，正 lateral 表示左移，正 turn 表示右转。混合后若最大轮命令超过 1000，则三轮同比例归一化，保持运动方向不变。

```c
/* 代码 3 三轮全向运动混合 */
left  = forward + turn - lateral / 2;
right = forward - turn + lateral / 2;
rear  = -lateral;
if (max(abs(left), abs(right), abs(rear)) > 1000)
    scale all three wheel commands proportionally;
```

横移、低速接近和越障前进时启用独立轮级 PI。命令到目标速度的比例为 1:2 counts/s，50 ms 更新一次；实测速度使用一阶平滑。PWM 由静摩擦前馈、比例项和积分项相加，并在下限与 500 之间限幅。积分限幅为 ±1200，同时采用条件积分避免在饱和方向继续累积。首次启动保留较高 PWM 脉冲，获得首个测速样本后再降到不同方向的运行下限。

```c
/* 代码 4 轮级 PI 控制逻辑 */
target_cps   = 2 * abs(target_command);
filtered_cps = (3 * filtered_cps + raw_cps) / 4;
error        = target_cps - filtered_cps;
integral     = clamp(integral + error * dt, -1200, 1200);
pwm          = clamp(feedforward + error / 2 + integral / 4,
                     running_minimum_pwm, 500);
```

### 4.7 红蓝球与洞口检测

推球视觉先对每个像素分类。红球采用 R−G≥25 且 R−B≥25；蓝球采用 B−R≥25、B−G≥25，并增加 B≥50 和饱和度≥45。洞口仅在远端区域检测暗且低饱和像素，防止近处阴影进入候选。分类图经过扫描线连通域提取，再按面积、包围盒填充率、长宽比和主轴比筛除噪声；蓝球还要求连通域具有至少 3 级亮度跨度，用球面明暗变化拒绝平坦蓝色色块。

```c
/* 代码 5 视觉像素分类条件 */
if (r - g >= 25 && r - b >= 25)            class = RED;
else if (b - r >= 25 && b - g >= 25 &&
         b >= 50 && saturation >= 45)      class = BLUE;
else if (in_far_band && dark && low_sat)   class = POCKET;
else                                       class = BACKGROUND;
```

### 4.8 推球入洞状态机

| 状态 | 动作与退出条件 |
|------|----------------|
| START_FORWARD | 从终点固定短直行 650 ms，建立可重复起始位姿 |
| FIND_BALL / SCAN | 寻找当前颜色；无目标则以编码器计数控制四段旋转扫描 |
| APPROACH_BALL | 先横移居中，再在远场修正朝向并分档前进；满足条件可进入 FAR_SPRINT |
| ALIGN | 只横移、不前进、不旋转；把球中心移到目标洞口列，稳定 300 ms |
| BACKOFF | 球进入保险杠距离时后退 220 计数，再回到 ALIGN |
| FAR_SPRINT | 远处小球已与洞口对齐时按图像 y 估算行程并开环冲刺 |
| PUSH | forward=300 纯直线强推 650 ms，随后按任务序号离场 |
| EGRESS / POST_EGRESS | 后退 1000 计数，再右转约 120°并前进 1000 计数寻找第二球 |
| DONE / FAULT_STOP | 两球完成或发生超时堵转；均粘滞停车 |

任务映射为红球至左洞、蓝球至右洞。视觉帧率低于 10 ms 控制频率，因此每个 frame_seq 只消费一次；两帧之间保持上次对位命令，避免对同一帧重复积分。推球阶段关闭超声波避障，因为球和桌沿会被前向测距误认为障碍物。

### 4.9 人机交互与诊断

系统建立名为 `vison_car` 的 Wi-Fi 热点，浏览器访问 `192.168.4.1` 可查看方向修正后的 MJPEG 图像、四个伪红外采样块以及算法判定；`/status` 接口输出掩码、图像尺寸、球洞像素计数和帧统计。LCD 周期显示巡线、避障、距离、编码器和摄像头状态。串口日志输出状态迁移、运动分量、图像年龄、丢帧与解码失败计数，为现场调参提供统一观测面。

## 5 课题开发与调试中出现的问题分析

| 问题现象 | 原因分析 | 解决方法 | 验证方式 |
|----------|----------|----------|----------|
| 物理红外接口受限，视觉与巡线算法重复 | 两套传感通路导致逻辑分叉 | 用摄像头生成兼容的 4 bit 伪红外掩码，复用原巡线状态机 | 伪红外几何与格式单测 |
| 直线居中时偶发全白 | 两个内侧采样块之间存在中心死区 | 将 CH2/CH3 中心调整到 54% 和 47%，使中心黑线同时点亮 | 60×40 真实尺寸边界测试 |
| 软件解码时延增大并出现旧帧控制 | JPEG 解码和 Wi-Fi 竞争 CPU，帧队列积压 | 解码任务绑定 core 1，回调仅复制，忙时丢新帧，并检查 frame age | 日志 frames / drop / dec / age |
| 低速横移或越障时某轮不转 | 静摩擦、轮间负载和电机差异造成开环 PWM 失效 | 启动脉冲 + 三轮独立 PI + 最低运行 PWM + 条件抗饱和 | 精确 PWM 数值单测和 speed_loop 日志 |
| 弯道外侧传感块一亮就猛转 | 外侧通道直接进入加权误差，宽线也被当急弯 | 普通 PD 只用内侧通道；外侧通道仅用于 30 ms 武装和全白确认 | 急弯候选时序测试 |
| 丢线后盲目沿最后方向搜索，可能越扫越远 | 搜索方向依赖瞬时误差且没有里程边界 | 固定右 120° 再左 240°，用编码器定段并设置堵转及总超时 | 正负编码器极性与两段耗尽测试 |
| 横条或单帧噪声误触发终点 | 单帧 0x0F 缺少时间确认 | 连续 3 帧全黑后锁存终点；普通停止不得进入推球 | 终点确认复位测试 |
| 贴近球时转向导致球侧滚并丢失 | 近场转向改变接触方向 | 远场完成朝向修正；ALIGN 只横移，稳定后纯直线推球 | 推球状态输出分量断言 |
| 蓝色车体或平坦色块被识别为蓝球 | 仅颜色阈值无法区分球面与结构件 | 限制 y 范围并增加连通域形状、球面亮度梯度条件 | 阴影、平坦块、蓝色噪点合成图测试 |
| 摄像头启用后原生 USB 串口断开 | GPIO19/20 被 USB UVC 占用 | 烧录与监视改用板载 UART 下载口 | 硬件接线和运行日志确认 |

## 6 创新点

1. **单摄像头多任务复用**：同一 UVC 摄像头在巡线阶段生成四路数字掩码，在推球阶段完成彩球和洞口识别，减少传感器重复并保持原巡线接口。
2. **按任务动态切换解码尺度**：60×40 保证巡线效率，120×80 提升远处小球分辨率，把算力分配与任务需求绑定。
3. **可测试的纯状态机架构**：巡线、避障和推球逻辑不直接访问硬件、不阻塞，可在 PC 上快速验证复杂时序。
4. **开环与闭环混合驱动**：高速巡线保留低延迟开环控制，横移和低速关键阶段自动切换轮级 PI，兼顾响应与抗堵转。
5. **基于连通域形状和球面亮度梯度的轻量视觉**：在不引入神经网络的情况下提高对阴影、车体和扁平色块的拒绝能力。
6. **可观测性设计**：网页实时叠加、JSON 状态、LCD 和串口日志同时呈现采样块、目标像素、帧年龄和轮速，缩短现场定位时间。

## 8 总结与改进方向

本课题完成了从物理红外巡线避障基线到单摄像头多任务视觉小车的迭代。最终系统形成统一的四层软件架构，以状态机串联巡线、避障、终点切换和两球推送，并以编码器反馈、超时与堵转保护提高实车可控性。宿主机测试证明核心离散逻辑在当前参数下满足预期。

当前方案仍有明确边界：色度阈值依赖现场光照；推球 PUSH 状态按时间结束，尚未通过洞口遮挡或球消失确认真实入袋；编码器计数用于相对里程但未建立完整位姿估计；参数主要来自单场地标定。后续可加入自动白平衡标定、视觉入洞确认、IMU 融合里程计、参数在线记录以及多次实车统计，从而提高跨场地鲁棒性。

### 拍摄镜头清单（按此顺序一镜到底或分段拼接）

1. **上电等待**：上电 → LCD 亮起 → 串口/网页显示 `vison_car` 就绪 → 静止 3 s。
2. **视觉巡线**：沿黑线稳定行驶，直道居中、过弯不冲出（可叠加网页采样块亮灭画面）。
3. **一次性避障**：靠近障碍减速 → 制动 → 左横移绕行 → 越障前进 → 右移找回黑线 → 恢复巡线。
4. **终点确认**：到达黑色横条，LCD/日志显示停车并切换 PUSH 模式。
5. **红球入左洞**：找到红球 → 横移对准 → 直线推入左洞 → 后退离场。
6. **蓝球入右洞**：转向寻找蓝球 → 对准右洞 → 推入 → 后退。
7. **最终停车**：两球完成后小车粘滞停车，LCD/日志显示 DONE。
