# 三轮全向车巡线功能方案

## 总体设计

在现有 ESP32-S3 四路红外传感器和三电机驱动代码上，增加两层控制：

1. 巡线控制器：根据黑线位置计算转向量。
2. 三轮运动学层：把“前进速度 + 转向量”转换为左、右、后三轮 PWM。

第一版采用 10 ms 控制周期、开环 PD 控制，支持连续黑线、弯道、短时丢线恢复和安全停车，不接入编码器闭环。

## 关键实现

- 四路传感器从左到右使用权重 `CH4=-3、CH3=-1、CH2=+1、CH1=+3`，对检测到黑线的通道求加权平均，得到连续位置误差。
- 将传感器连续确认次数从 3 次调整为 2 次，使滤波延迟由约 30 ms 降至约 20 ms。
- PD 输出采用：
  - `turn = Kp × error + Kd × (error - last_error)`
  - 初始参数：`Kp=70`、`Kd=30`、转向限幅 `±250`
  - 基础前进速度 `220/1000`
  - 弯道按误差降低前进速度，最低 `140/1000`
- 新增巡线状态机：
  - `TRACKING`：正常计算误差和 PD 输出。
  - `LOST_SEARCH`：四路全白时，按最后一次偏差方向低速转向搜索。
  - `STOPPED`：丢线超过 1.5 秒、持续全黑超过 100 ms、初始化失败时停车。
  - 上电初始化完成后等待 3 秒再启动，便于安全放车。
- 对不连续的异常图案，例如 `BWWB`，短时保持最后有效误差并降速；持续超过 100 ms 后按丢线处理。
- 串口仅在状态变化或每 100 ms 输出一次误差、PD、三轮输出，避免日志阻塞控制循环。

## 三轮全向混控

按“前左、前右、后中，约 120°分布”的标准全向底盘建立逻辑接口：

```c
drive_set_motion(forward, turn);
```

其中 `turn > 0` 表示向右修正。标准混控初值为：

```text
left  = -0.866 × forward + turn
right = +0.866 × forward + turn
rear  =                    turn
```

计算后统一按比例限幅到 `-1000..1000`，保持三轮速度比例。电机物理方向通过现有 `MOTOR_*_REVERSED` 配置修正，不在巡线算法中散布方向判断。

新增模块接口：

```c
esp_err_t drive_init(void);
esp_err_t drive_set_motion(int forward, int turn);
esp_err_t drive_stop(void);

line_follow_result_t line_follow_update(
    uint8_t black_mask,
    uint32_t elapsed_ms
);
```

`line_follow_result_t` 包含巡线状态、位置误差、前进量、转向量和三个电机目标值，便于日志和后续编码器闭环复用。

## 调试与验收

- 构建检查：ESP-IDF 5.4.x 下完整编译，传感器、电机 GPIO 重复时拒绝启动。
- 架空测试：
  - `forward > 0` 时车轮组合对应车体前进。
  - 正转向量对应车体右转，负值对应左转。
  - 停车状态下三个 PWM 均为零。
- 桌面推车测试：依次验证各个传感器位置对应正确的左右修正方向。
- 低速赛道测试：
  - 先将 `Kd=0`，增加 `Kp` 到能过弯但尚未明显振荡。
  - 再增加 `Kd` 抑制摆动。
  - 最后逐步提高基础速度并增加弯道降速。
- 验收标准：
  - 连续完成测试赛道 3 圈且不冲出黑线。
  - 短时丢线后能按原偏差方向重新找到黑线。
  - 丢线 1.5 秒仍未恢复时停车。
  - 持续全黑后 150 ms 内停车。
  - 控制循环保持 10 ms 周期且无阻塞延时。

## 假设与边界

- 黑线位于白色背景，传感器检测黑色时输出低电平。
- 四路传感器安装顺序保持 CH4、CH3、CH2、CH1 从左到右。
- 实际红外 GPIO 需要在实施前填入配置；当前工程中的四个值仍为 `-1`。
- 第一版只处理连续线路；十字路口、分叉和终点图案不纳入自动决策。
- 编码器 GPIO 尚未确定，因此第一版不开速度闭环，但运动接口保留后续增加编码器 PI 内环的能力。
