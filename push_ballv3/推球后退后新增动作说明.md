# 推球后退后新增动作修改说明

## 📋 修改概述

在红球推入洞后的后退阶段（EGRESS）和寻找蓝球阶段（FIND_BALL）之间，新增两个动作：
1. **右转50度** - 调整车头方向
2. **向前移动一段距离** - 移动到更容易发现蓝球的位置

## 🎛️ 参数说明与推荐值

### 右转参数

| 参数 | 当前值 | 推荐范围 | 说明 |
|------|--------|----------|------|
| `PUSH_POST_EGRESS_TURN_DEG` | 50 | 30-70 | 右转角度，建议根据现场调整 |
| `PUSH_POST_EGRESS_TURN_SPEED` | 200 | 180-230 | 右转速度（PWM）。OPEN 模式把该值直接当 PWM，<100 会失速停转 |

**角度计算公式**:
```c
编码器计数 = PUSH_SCAN_30_DEG_COUNTS × 角度 / 30
            = 160 × 50 / 30
            ≈ 267 计数
```

### 前进参数

| 参数 | 当前值 | 推荐范围 | 说明 |
|------|--------|----------|------|
| `PUSH_POST_EGRESS_FORWARD_COUNTS` | 1000 | 800-1500 | 前进距离（编码器计数） |
| `PUSH_POST_EGRESS_FORWARD_SPEED` | 80 | 60-120 | 前进速度 |

**距离换算**:
- 当前 1000 计数 ≈ 1000 / 1560 ≈ **0.64 轮圈**
- 假设轮子直径 65mm，周长 ≈ 204mm
- 1000 计数 ≈ **130mm** (约13cm)

### 新流程
```
推红球入洞 (PUSH)
    ↓
后退脱离桌边 (EGRESS, 2000计数)
    ↓
右转50度 (POST_EGRESS_TURN, 267计数)
    ↓
前进寻找位置 (POST_EGRESS_FORWARD, 1000计数)
    ↓
找蓝球 (FIND_BALL)
```

### BALL_PUSH_POST_EGRESS_TURN (Line 272-280)
```c
case BALL_PUSH_POST_EGRESS_TURN: {
    bool stalled = tick_counts(c, ms, l, r);
    if (stalled) { c->state = BALL_PUSH_FAULT_STOP; return zr(c, true); }
    out.turn = PUSH_POST_EGRESS_TURN_SPEED;  // 右转
    out.active = true;
    out.drive_mode = BALL_DRIVE_OPEN;
    if (c->stage_progress >= c->stage_target) {
        // 右转完成，切换到前进状态
        reset_stage(c, BALL_PUSH_POST_EGRESS_FORWARD,
                   PUSH_POST_EGRESS_FORWARD_COUNTS, l, r);
        out.state_changed = true;
    }
    break;
}
```

```c
case BALL_PUSH_POST_EGRESS_FORWARD: {
    bool stalled = tick_counts(c, ms, l, r);
    if (stalled) { c->state = BALL_PUSH_FAULT_STOP; return zr(c, true); }
    out.forward = PUSH_POST_EGRESS_FORWARD_SPEED;  // 前进

        out.state_changed = true;
```

## 🧪 测试建议

### 1. 参数调优流程

#### 第一步：测试右转角度
- 将 `PUSH_POST_EGRESS_FORWARD_COUNTS` 设为 0（暂时跳过前进）
- 观察50度右转后，车头朝向是否合适
- 根据实际效果调整 `PUSH_POST_EGRESS_TURN_DEG`

#### 第二步：测试前进距离
- 恢复前进功能
- 观察1000计数前进后，小车位置是否适合寻找蓝球
- 根据实际效果调整 `PUSH_POST_EGRESS_FORWARD_COUNTS`

#### 第三步：速度调优
- 如果转得太快导致不稳，降低 `PUSH_POST_EGRESS_TURN_SPEED`
- 如果前进太快冲出视野，降低 `PUSH_POST_EGRESS_FORWARD_SPEED`

### 2. 观察要点

| 观察项 | 合理状态 | 不合理状态 | 调整建议 |
|--------|----------|------------|----------|
| 右转后车头 | 朝向蓝球区域 | 朝向错误或过度 | 调整 `PUSH_POST_EGRESS_TURN_DEG` |
| 前进后视野 | 蓝球在视野中心 | 蓝球在边缘或视野外 | 调整 `PUSH_POST_EGRESS_FORWARD_COUNTS` |
| 总耗时 | 合理（<3秒） | 太长（>5秒） | 提高速度或减少距离 |
| 运动稳定性 | 平稳 | 抖动或失控 | 降低速度 |

### 3. 常见问题

**问题1**: 右转后找不到蓝球
- **原因**: 角度不够或方向错误
- **解决**: 调整 `PUSH_POST_EGRESS_TURN_DEG`（增加或减少）

**问题2**: 前进后小车离蓝球太远
- **原因**: 前进距离不够
- **解决**: 增加 `PUSH_POST_EGRESS_FORWARD_COUNTS`

**问题3**: 前进后小车离蓝球太近，视野受限
- **原因**: 前进距离太大
- **解决**: 减少 `PUSH_POST_EGRESS_FORWARD_COUNTS`

**问题4**: 右转或前进时小车抖动
- **原因**: 速度太快
- **解决**: 降低对应的 `SPEED` 参数

## ⚠️ 注意事项

1. **只在推第一球（红球）后执行**
   - 推第二球（蓝球）后直接进入 `BALL_PUSH_DONE`，不会执行新增动作

2. **编码器计数必须精确**
   - 修改 `PUSH_POST_EGRESS_TURN_DEG` 会自动计算编码器计数
   - 手动修改 `PUSH_SCAN_30_DEG_COUNTS` 会影响角度精度

3. **右转速度是原始 PWM，不是抽象速度**
   - 右转走 `BALL_DRIVE_OPEN` → `drive_set_motion()`，把 `turn` 值直接当 PWM（0-1000）
   - `PUSH_POST_EGRESS_TURN_SPEED` 需 ≥ 180，否则轮子失速停转（原值 80 过低，已改为 200）
   - 参考已校准的 `LINE_SEARCH_TURN=230` / `LINE_CORNER_ROTATE_TURN=200`
   - `PUSH_POST_EGRESS_FORWARD_SPEED` 走 APPROACH 反馈（有速度 PI），≤ 120 仍有效

4. **现场测试必不可少**
   - 不同场地的光照、桌布颜色、球的位置都不同
   - 必须在实际环境中调优参数
